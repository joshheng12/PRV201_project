# Start here

1. Open `results/demo/report.html` to inspect the working prototype output immediately.
2. Read `README.md` to install and run the project.
3. Read `docs/DESIGN.md` for the design document and architecture.
4. Use `docs/SUBMISSION_CHECKLIST.md` to prepare your actual M3 submission.
5. Use `docs/DEMO_SCRIPT.md` when recording your demonstration.

All named stacks are implemented: Python, scikit-learn, PyTorch, Hugging Face Transformers, Claude, OpenAI API, AWS Bedrock, Azure OpenAI, and a FastAPI delivery endpoint.

The bundled data is synthetic. Real-video collection, independent human review, actual frame inference, and credentialed provider runs still need to be completed before claiming the full planned system was executed. Exact verification details are in `docs/VERIFICATION.md`.
