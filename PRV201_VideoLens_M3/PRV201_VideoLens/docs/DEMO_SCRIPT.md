# Five-minute demonstration

1. **Problem (30 seconds).** Explain the question: which metadata/content features are associated with engagement within one YouTube sample? State that association is not causation.
2. **Data (45 seconds).** Show the observed CSV, sample size, sampling protocol, collection time, and exclusions. If using bundled demo data, say clearly that it is synthetic.
3. **Execution (60 seconds).** Show the CLI command and execute it with a new output folder. Point out actual stack statuses; show cloud errors honestly if present.
4. **Results (60 seconds).** Open report.html. Explain engagement definition, sample-relative higher/lower groups, three numeric features, and category medians. Distinguish model MAE from accuracy.
5. **Validation (45 seconds).** Show ten human labels and agreement. Describe a disagreement and its likely source. Explain creator holdout and baseline comparison.
6. **Evidence and limits (60 seconds).** Show execution trace, manifest, separate frame classifications, and provider statuses. Explain the weak seed classifier, small sample, confounders, and next improvements.

Avoid saying the system watches full videos, proves what causes virality, achieves 80% classification accuracy without real reviews, or has used a cloud integration just because its source code exists.
